# Breathe Match: Respiratory System Memory Game

A memory card game built with HTML, CSS and JavaScript. Match each part of the respiratory system with what it does, for example Alveoli with "Tiny air sacs where oxygen and carbon dioxide are exchanged".

**Live demo:** https://samiuallahganaie.github.io/respiratory-memory-game/

## Features
- 12 respiratory system terms, each paired with a short description of its function
- Three difficulty levels: Easy (6 pairs), Medium (9 pairs) and Hard (12 pairs)
- Cards are shuffled every game
- A short fact appears each time you make a correct match
- Move counter, timer and a 1 to 3 star rating
- Best score for each level is saved in the browser
- Responsive layout that works on phones and desktops
- Keyboard-friendly buttons and screen reader labels

## Run it locally
No installation is needed. Download the repository and open `index.html` in a browser.

## What I practised
- DOM manipulation and game logic in plain JavaScript
- CSS 3D transforms for the card flip animation
- CSS Grid for a layout that changes with screen size
- Saving data with `localStorage`
- Testing the game in a browser and fixing layout problems on small screens
